Detailed Description

Tokenizes arguments string of the form: preamble <prefix>value <prefix>value ...
e.g. some preamble text t/ 11.00 t/12.00 k/ m/ July where prefixes are t/ k/ m/.

  1. An argument's value can be an empty string e.g. the value of k/ in the above example.
  2. Leading and trailing whitespaces of an argument value will be discarded.
  3. An argument may be repeated and all its values will be accumulated e.g. the value of t/ in the above example.

int seedu.address.logic.parser.ArgumentTokenizer.findPrefixPosition ( String argsString,
String prefix,
int fromIndex )
inlinestaticprivate

Returns the index of the first occurrence of prefix in argsString starting from index fromIndex. An occurrence is valid if there is a whitespace before prefix. Returns -1 if no such occurrence can be found.

E.g if argsString = "e/hip/900", prefix = "p/" and fromIndex = 0, this method returns -1 as there are no valid occurrences of "p/" with whitespace before it. However, if argsString = "e/hi p/900", prefix = "p/" and fromIndex = 0, this method returns 5.
