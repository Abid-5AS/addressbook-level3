90 /*
91 * TODO: the code below can be removed once the bug reported here
92 * https://bugs.openjdk.java.net/browse/JDK-8131666
93 * is fixed in a later version of the SDK.
94 *
95 * According to the bug report, TextInputControl (TextField, TextArea) will
96 * consume function-key events. Because CommandBox contains a TextField and
97 * ResultDisplay contains a TextArea, some accelerators (e.g., F1) will
98 * not work when the focus is in them because the key event is consumed by
99 * the TextInputControl(s).
100 *
101 * For now, we add the following event filter to capture such key events and open
102 * the help window purposely so as to support accelerators even when focus is
103 * in CommandBox or ResultDisplay.
104 */
105 getRoot().addEventFilter(KeyEvent.KEY_PRESSED, event -> {
106 if (event.getTarget() instanceof TextInputControl && keyCombination.match(event)) {
107 menuItem.getOnAction().handle(new ActionEvent());
108 event.consume();
109 }
110 });
