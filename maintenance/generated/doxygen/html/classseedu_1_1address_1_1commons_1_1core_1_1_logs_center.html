Detailed Description

Configures and manages loggers and handlers, including their logging level. Named Loggers can be obtained from this class.
These loggers have been configured to output messages to the console and a .log file by default, at the INFO level. A new .log file with a new numbering will be created after the log file reaches 5MB in size, up to a maximum of 5 files.
